# Code of Conduct

## Our pledge

We want participating in this project to be a harassment-free experience for
everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal appearance,
race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful of differing viewpoints and experiences.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its community.
- Show empathy towards other community members.
- Credit others' work and respect attribution requirements.

## Unacceptable behaviour

- Harassment, insults, or derogatory comments.
- Discriminatory jokes or language.
- Publishing others' private information without permission. This includes
  member data: **never** put real member records, email addresses, or
  credentials into an issue, pull request, test fixture, or commit.
- Sustained disruption of discussions or deliberate bad-faith argument.
- Other conduct that would reasonably be considered inappropriate in a
  professional setting.

## Scope

This code of conduct applied to this project's spaces while it was active — issues, pull
requests, discussions, commit messages and documentation. In a fork, it applies to
that fork's spaces, and the fork is responsible for enforcing it.

## Reporting

This project has been handed over and is not actively maintained, so no enforcement contact
is published and conduct reports are not handled here. Each fork is
responsible for enforcing its own code of conduct in its own spaces, and should
publish its own reporting route.
